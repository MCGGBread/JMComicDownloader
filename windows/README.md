# JMComic 客户端

基于 [JMComic-Crawler-Python](https://github.com/hect0x7/JMComic-Crawler-Python) 的 Windows 桌面客户端。
输入番号 → 自动下载 → 打包 ZIP → 解包 → 合成 PDF，全部在一个窗口里完成。

- **便携运行**：单文件 `JMComicClient.exe`，双击即用，不写注册表、不装 Python。
- **配置与数据都在 exe 同级目录**：`config/`、`crawled_data/`、`logs/`。
- **多种番号输入格式**：`jm54747电梯（极品）`、`47228，118983，152470`、18comic 链接等可混合粘贴。
- **批量队列**：逐条下载，实时进度；运行中可继续粘贴番号「追加任务」，不用等上一批结束；可随时停止。
- **断点续传**：关闭应用后，没跑完的任务队列会保存下来，下次打开自动接着跑。
- **自动产出 PDF**：每本一个 PDF，按页序合成，支持质量 / 最大宽度调节。
- **爬取记录**：记录爬过的番号、标题、页数、时间、PDF 路径，支持搜索、导出 CSV、一键重新爬取。

## 快速开始

1. 把 `JMComicClient.exe` 放到任意文件夹（例如 `D:\JMComic\`）。
2. 双击运行。首次启动会自动创建：

```
D:\JMComic\
├── JMComicClient.exe
├── config\
│   ├── config.json          你的设置
│   ├── option_api.yml       自动生成的 jmcomic 配置
│   ├── crawled_history.json 爬取过的番号
│   └── queue_state.json     未完成的任务队列（全部完成后自动删除）
├── crawled_data\            默认存储目录（可在设置里改）
│   ├── images\              下载的原图（可选保留）
│   ├── zip\                 打包好的 ZIP
│   ├── unpacked\            解包临时目录
│   └── pdf\                 ★ 最终 PDF
└── logs\app.log
```

3. 在输入框粘贴番号，点「开始爬取」。

### 运行中追加任务

任务开始后输入框会重新变为可编辑，按钮变成「追加任务」。把新番号粘进去再点一下，
任务会排到队尾，当前下载不会中断：

- 总进度按「已完成 / 队列总数」实时变化，追加后总数会变大。
- 已在队列里、正在下载或已完成的番号会自动忽略；失败 / 已取消的可以重新添加来重试。
- 「停止」会中断当前任务，并把所有还没开始的排队任务标记为已取消。

### 关闭后继续

队列会实时写入 `config/queue_state.json`。关掉应用（哪怕正在下载）再打开：

- 任务列表原样恢复，正在下载的那条回到「等待」，已完成的保持完成状态。
- 默认 1 秒后自动继续；不想要自动开始的话，在「设置 → 输出设置」里关掉
  「启动时自动继续未完成任务」，之后点「开始爬取」即可手动继续。
- 已下载的图片有缓存，续跑不会从头再下一遍。
- 任务列表会一直保留：下次打开仍能看到上次的队列和结果（完成 / 失败 / 已取消）。
  想清掉旧列表，点任务队列右上角的「清空列表」；开始一批全新任务时也会自动清空旧列表。

## 支持的输入格式

全部可混排，重复番号自动去重、顺序保留：

```
jm54747电梯（极品）
jm28650体育用具储藏室（极品）

142176(母子大车)404477(长篇大车，经典作品)404098(狐娘)431896(熟女)
142176（母子大车）404477
142176【母子大车】404477
推荐142176(母子大车)

h540931(瞬)-h499835(幼瞬)
h486483(日奈)-h479035(日奈)
500703(柚子)-h559091(柚子)
【格黑娜】22

47228，118983，152470，197393，219269
JM-54747 / JM 28650 / [JM100]
54747 电梯
https://18comic.vip/album/54747/
aid=54747
```

识别规则：

- 括号注释紧贴也能切开：`142176(母子大车)404477(...)` → 142176、404477，括号里带中文逗号也不影响。
- 半角 `()`、全角 `（）`、方头 `【】`、`[]` 都支持；括号前有「推荐」这类中文也能认。
- `h` 前缀也认：`h540931` → 540931，可以和纯数字混写（`500703(柚子)-h559091(柚子)`）。
  为避免误伤，`h` 后面至少 4 位，所以 `h264`、`H100`、`4h30m` 不会被当成番号。
- 纯数字至少 3 位；带 `jm` 前缀时 2 位也认。
- 分类标题里的计数不会误判：`【格黑娜】22`、`【千年】36` 识别为空。
- 日期、版本号、量词不会被误判：`2024-10-26`、`版本2.5.36`、`2024年10月`、`第2话`、`共35页`、`(C88)` 都识别为空。

## 设置项

| 分类 | 说明 |
| --- | --- |
| 存储根目录 | 相对路径基于 exe 目录，也可以填绝对路径（如 `D:\本子`） |
| 客户端实现 | `api`（兼容性好，默认）/ `html`（效率高）；失败可自动切换 |
| 图片并发 / 章节并发 | 默认 30 / 8，过高容易触发限流 |
| 网络代理 | `system` 跟随系统 · `none` 直连 · 或填 `127.0.0.1:7890` |
| Cookie AVS | 少数需要登录的题材，填浏览器里名为 `AVS` 的 Cookie |
| 自定义域名 | 内置域名失效时手动指定，逗号或换行分隔 |
| PDF 质量 / 最大宽度 | 质量 50~100；宽度 0 表示保持原尺寸 |
| 文件命名 | 默认 `JM{id} {title}`，可用 `{id} {title} {author} {pages}` |
| 保留原图 / ZIP / 解包目录 | 默认只留 ZIP + PDF，原图与解包目录会自动清理 |
| 启动时自动继续未完成任务 | 默认开启；关闭后需手动点「开始爬取」继续上次队列 |

修改后对下一个任务生效，无需重启。

## 输出说明

- ZIP：`crawled_data\zip\JM54747 标题.zip`（内含图片和 `_info.json` 元信息）
- PDF：`crawled_data\pdf\JM54747 标题.pdf`，一页一图，按章节/页码自然排序
- 记录：`config\crawled_history.json`，在「记录」页可搜索、导出 CSV、重新爬取

## 常见问题

**一直失败 / 超时**
先确认网络能访问禁漫。国内网络通常需要代理：设置里把「网络代理」改成 `127.0.0.1:7890`（按你的代理端口改）。
也可以把「客户端实现」在 `api` 和 `html` 之间切换试试；仍不行就在「自定义域名」里填一个可用的镜像域名。

**提示没有下载到图片**
多为域名被墙、番号不存在，或该本子需要登录。可先点「解析预览」确认番号识别正确，再检查代理。

**杀毒软件报毒**
PyInstaller 单文件程序常被误判为加壳。可以加入信任，或改用源码运行（见下）。

**PDF 打开是空白 / 顺序乱**
PDF 按文件名自然排序（`2` 在 `10` 前面）。若图片本身命名混乱，顺序也会跟着乱。

**换电脑 / 换目录**
把整个文件夹拷走即可，路径都记录为相对路径。

## 从源码运行 / 自行打包

需要 Python 3.10+（带 tkinter 的官方发行版）。

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

打包成 exe：

```bat
.venv\Scripts\pip install pyinstaller
.venv\Scripts\python build.py
```

> 打包前会自动把 `dist\config`（设置 + 爬取历史）复制到 `backups\config-时间戳\`，
> 只保留最近 10 份；`crawled_data` 与自定义存储目录不会被改动。

产物在 `dist\JMComicClient.exe`。也可以直接双击 `build.bat` 一键完成。

自检（不联网 / 联网两种）：

```bat
dist\JMComicClient.exe --selftest
dist\JMComicClient.exe --selftest --network
```

## 目录结构（源码）

```
main.py              入口（DPI、日志重定向、自检开关）
app/
  runtime.py         便携目录、日志重定向、打开文件
  config.py          config.json 读写 + option.yml 生成
  parser.py          番号解析（多种格式）
  pipeline.py        下载 → ZIP → 解包 → PDF
  pdf.py             轻量 PDF 生成（JPEG 直嵌，低内存）
  history.py         爬取记录
  fsutil.py          文件工具（自然排序、安全文件名）
  ui/                界面（主题、控件、主窗口）
tools/               开发用截图 / UI 冒烟测试
```
